OBSIDIAN PRO — Premium Article Reading Website

OBSIDIAN PRO is a frontend design demo of a modern premium article-reading platform. It is designed to explore an elegant reading experience through clean layouts, beautiful typography, smooth interactions, and responsive design.

Note: This project is currently a frontend-only demonstration built with HTML, CSS, and JavaScript. It does not include a fully functional backend, database, authentication system, or real subscription/payment functionality.

Purpose: To demonstrate the visual design, user interface, and frontend experience of a premium digital reading platform.
